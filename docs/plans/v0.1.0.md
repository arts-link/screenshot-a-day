# Screenshot-a-Day v0.1.0 implementation plan

Status: locally implemented and published for draft review

## Goal

Deliver a documented, AGPL-licensed, self-hosted visual-history service that can schedule reproducible captures, compare results, publish galleries and animations, and notify external systems of meaningful changes.

## Acceptance criteria

1. A new operator can launch with Docker Compose and finish one-time setup.
2. A project can capture all enabled browser profiles manually, through the API, or on a schedule.
3. History, comparisons, GIF/WebM exports, and private/unlisted/indexable sharing work without exposing secrets.
4. Signed change webhooks and worker retry/recovery behavior are testable and documented.
5. The UI, API, images, changelog, and Git tag agree on the exact SemVer release.

## Decision log

| Area       | Decision                                                                                |
| ---------- | --------------------------------------------------------------------------------------- |
| Product    | Self-hosted app for individual developers; SaaS extension points only                   |
| Runtime    | Split TypeScript API/web and Playwright worker processes                                |
| Storage    | SQLite metadata and local blobs behind an adapter                                       |
| Capture    | Chromium, Firefox, and WebKit; multiple named profiles per project                      |
| Scheduling | Presets plus cron/timezone; capture all profiles; coalesce overlap                      |
| Security   | Single administrator; encrypted headers/cookies; private targets blocked with allowlist |
| History    | PNG originals, WebP thumbnails, configurable retention                                  |
| Comparison | Side-by-side, overlay, SHA-256, pixel heatmap, and change percentage                    |
| Publishing | GIF and WebM; private, unlisted, and indexable galleries                                |
| Alerts     | Threshold-signed webhooks; optional failure events                                      |
| License    | AGPL-3.0-or-later                                                                       |
| Releases   | SemVer, Changesets, Conventional Commits, coordinated packages and images               |
| UX         | Manual capture actions remain locked to their active batch and announce live progress   |

## Progress policy

Every implementation increment updates this checklist or the relevant architecture, operations, API, or user documentation. Architectural reversals require a superseding ADR.
