Privacy

The application is yours.
The marketing site is measured lightly.

Self-hosted application

Screenshot-a-Day installations include no product telemetry and do not report captures, projects, targets, usage, credentials, or operator activity to Arts-Link. An operator can separately choose to configure analytics for a gallery they publish; that optional configuration belongs to that operator and is not enabled by Arts-Link.

Public marketing site

This GitHub Pages marketing site uses PostHog to count anonymous page views and measure clicks on release, demo, source, documentation, and installation actions. It also records when the installation command is copied, but never records the command text.

Analytics runs in cookieless mode. It creates no analytics cookies or browser-storage identifiers, creates no person profiles, and does not use session replay, heatmaps, autocapture, surveys, feature flags, exception capture, or performance capture. Analytics must remain disabled unless the PostHog project is configured to discard visitor IP addresses.

Campaign and browser information

Events can include the page path, referring site, browser/device information supplied by PostHog, release version, CTA placement, destination category, and allowlisted utm_source, utm_medium, utm_campaign, and utm_content values. Query strings and fragments are removed from recorded page and referrer URLs. Campaign values are never intended to contain personal information.

Your browser preference

The marketing site does not initialize analytics when the browser sends Do Not Track or Global Privacy Control. Blocking the analytics request does not affect the content, installation instructions, demo, or source links.

Questions

Inspect the exact implementation in site/analytics.js. For privacy questions or requests, use the contact route at Arts-Link.
